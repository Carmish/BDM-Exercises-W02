# Exercise sklearn pipelines - wine quality

In this exercise you will practice working with `sklearn` pipelines. You will go through some of the typical steps in the ML model lifecycle:

* data loading
* data exploration
* splitting the data into train and test
* creating a model
* evaluating the model

You will be working with datasets related to wine quality. Each item in a dataset corresponds to a wine; based on its features, such as acidity, sugar levels, density, your model will predict the quality rating of a wine.

# How to get started
1. First press the green button on the right called **Use this template** > **Create a new repository** > Set it as **private** when creating it.
2. When you have a copy of the repository, there is **NO** need to add us as collaborators for this exercise.
3. Then, click on **<>Code**, then **Codespaces**, and finally **Create codespace on main**. When the codespace finishes building, the dependencies in requirements.txt should be automatically installed.
4. You can now start working on the exercise.
5. The rest of the steps are similar to previous exercises. That means when importing libraries in the codespace for the first time, you will have to:
   - At the top of the notebook, under Select Kernel you can click Install/Enable suggested extentions Python + Jupyter
   - When you are prompted again to select a kernel choose Python Environments.
   - Then select the recommended python environment.
   - Don't forget to commit and push changes.

Good luck!
